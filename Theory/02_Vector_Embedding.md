# 2단계: 벡터 임베딩 & 유사도 검색

---

## 벡터가 뭔가요?

벡터는 **여러 숫자의 묶음**입니다. 좌표라고 생각하면 쉬워요.

```
2D 좌표:  (3, 5)        ← 숫자 2개
3D 좌표:  (3, 5, 2)     ← 숫자 3개
768D 벡터: (0.2, -0.8, 0.1, 0.5, ...)  ← 숫자 768개
```

텍스트 임베딩 모델은 단어/문장을 보통 **수백~수천 차원**의 벡터로 변환합니다.

---

## 왜 벡터로 변환하는가?

> 핵심: **의미가 비슷한 것은 벡터 공간에서 가까이 위치합니다**

```
"강아지"  → [0.8, 0.1, 0.9, ...]
"puppy"   → [0.79, 0.11, 0.88, ...]  ← 가까움 (같은 의미)
"고양이"  → [0.7, 0.2, 0.85, ...]   ← 비교적 가까움 (둘 다 동물)
"자동차"  → [0.1, 0.9, 0.2, ...]    ← 멀음 (다른 의미)
```

단순한 숫자 변환이 아니라 **의미까지 담긴 변환**입니다.

---

## 유명한 예시: King - Man + Woman = Queen

```
벡터("왕")   - 벡터("남자") + 벡터("여자")
                    ↓
             ≈ 벡터("여왕")
```

벡터 연산만으로 단어 간의 **관계와 의미**가 표현됩니다.

---

## 코사인 유사도: 얼마나 비슷한가?

두 벡터가 얼마나 가까운지 측정하는 방법입니다.

```
코사인 유사도 = 1.0   → 완전히 같은 방향 (매우 유사)
코사인 유사도 = 0.0   → 직각 (관련 없음)
코사인 유사도 = -1.0  → 반대 방향 (반대 의미)
```

거리가 아니라 **방향**으로 유사도를 측정하기 때문에 텍스트에 적합합니다.

```python
from sklearn.metrics.pairwise import cosine_similarity

# "강아지"와 "puppy"의 임베딩 벡터가 있다면
similarity = cosine_similarity([강아지_벡터], [puppy_벡터])
# → 0.95 (매우 유사)
```

## 벡터 데이터베이스

수백만 개의 문서를 벡터로 저장하고, 빠르게 유사한 것을 찾아주는 DB입니다.

```
일반 DB:  "강아지 관련 문서 찾아줘" → SQL 키워드 검색
벡터 DB:  강아지_벡터 입력 → 의미적으로 유사한 문서 검색
```

| 벡터 DB | 특징 |
|---------|------|
| **FAISS** | Meta 개발, 빠름, 로컬 저장 |
| **Chroma** | 가볍고 설치 쉬움, 개발용으로 적합 |
| **Pinecone** | 클라우드 기반, 대규모 서비스용 |
| **Weaviate** | 오픈소스, 필터 검색 강력 |

## 전체 흐름 정리

```
문서들
  ↓
[임베딩 모델]  ← text-embedding-ada-002, BGE, E5 등
  ↓
벡터들 → [벡터 DB에 저장]

---

사용자 질문
  ↓
[임베딩 모델]
  ↓
질문 벡터 → [벡터 DB에서 유사 벡터 검색]
  ↓
관련 문서 반환
```

## 정리

| 개념 | 한줄 요약 |
|------|-----------|
| 벡터 | 텍스트를 의미를 담은 숫자 배열로 변환한 것 |
| 임베딩 | 텍스트 → 벡터 변환 과정 |
| 코사인 유사도 | 두 벡터가 얼마나 비슷한지 0~1로 측정 |
| 벡터 DB | 벡터를 저장하고 유사한 것을 빠르게 찾아주는 DB |
